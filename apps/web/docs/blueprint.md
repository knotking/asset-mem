# **App Name**: HomeGeek AI

## Core Features:

- Chat Interface: Clean, intuitive chat interface for users to type and send messages.
- Answer Generation: Call a Google Cloud Function to generate answers based on user input, incorporating a tool for deciding whether specific information is relevant.
- Response Display: Display responses from the Google Cloud Function in a clear, readable format within the chat.
- Chat History: Simple message logging in local storage. Limited by local storage size.

## Style Guidelines:

- Primary color: Saturated blue (#4285F4) to evoke trust and intelligence.
- Background color: Light desaturated blue (#E3F2FD) for a calming and unobtrusive backdrop.
- Accent color: Purple (#9C27B0) for highlighting important UI elements.
- Body and headline font: 'Inter' (sans-serif) for a clean and modern appearance.
- Use simple, outline-style icons to maintain a clean and modern aesthetic.
- Clean, single-column layout for easy readability and focus on the conversation.
- Subtle animations for message bubbles appearing, creating a smooth and engaging experience.
