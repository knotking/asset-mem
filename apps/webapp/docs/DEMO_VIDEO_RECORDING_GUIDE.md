## Pre-Recording Setup

### Technical Requirements

- **Screen Resolution**: 1920x1080 (Full HD) minimum, 2560x1440 (2K) recommended
- **Frame Rate**: 30fps minimum, 60fps for smoother transitions
- **Recording Software**: 
  - macOS: QuickTime Player, ScreenFlow, or OBS Studio
  - Windows: OBS Studio, Camtasia, or Windows Game Bar
  - Mobile: Built-in screen recording (iOS/Android)
- **Audio**: Clear narration or background music (optional)
- **Duration Target**: 3-5 minutes total

### Test Account Setup

1. Create a test account with sample data:
   - At least 2-3 properties
   - Multiple documents per property
   - Several chat sessions with AI interactions
   - 2-3 checkpoints with photos
   - Mix of property types (real estate, vehicle, appliance)

2. Prepare test content:
   - Sample property documents (invoices, receipts, manuals)
   - Test questions for AI chat
   - Sample photos for checkpoints

### Browser/Device Preparation

- **Webapp**: Use Chrome or Safari in incognito/private mode
- **Mobile**: Use a physical device or high-quality emulator
- Clear browser cache and ensure fresh login state
- Disable browser extensions that might interfere
- Close unnecessary applications to avoid notifications

## Recording Tips

### General Tips

1. **Practice First**: Run through the entire flow 2-3 times before recording
2. **Smooth Cursor Movement**: Move mouse cursor slowly and deliberately
3. **Pause for Loading**: Wait for pages/features to fully load before proceeding
4. **Clean UI**: Close unnecessary tabs, hide bookmarks bar, use clean browser state
5. **Consistent Speed**: Maintain consistent navigation speed throughout

### Webapp Specific

1. **Browser Zoom**: Set browser zoom to 100% for consistent appearance
2. **Window Size**: Use standard window size (not full screen) for better framing
3. **Hover Effects**: Pause briefly on interactive elements to show hover states
4. **Scroll Smoothly**: Use smooth scrolling, avoid jerky movements
5. **Click Indicators**: Make clicks visible (cursor change, button press animation)

### Mobile App Specific

1. **Device Orientation**: Use portrait mode for most screens, landscape for camera
2. **Touch Indicators**: Show finger taps clearly (use screen recording with touch indicators)
3. **Smooth Animations**: Let transitions complete before next action
4. **Real Device**: Prefer physical device over emulator for authentic feel
5. **Screen Brightness**: Ensure screen is bright and visible

### Transitions Between Platforms

1. **Fade Transition**: Use fade or crossfade when switching between web and mobile
2. **Split Screen**: Consider split screen to show both platforms simultaneously
3. **Clear Indication**: Use text overlay or narration to indicate platform switch
4. **Consistent Flow**: Maintain logical flow when switching platforms

### Audio (If Including Narration)

1. **Clear Audio**: Use good microphone, reduce background noise
2. **Pacing**: Speak clearly and at moderate pace
3. **Pauses**: Include brief pauses for visual actions
4. **Enthusiasm**: Maintain engaging tone
5. **Script**: Follow script but sound natural

## Post-Production Notes

### Editing Checklist

- [ ] Remove any mistakes or retakes
- [ ] Add smooth transitions between scenes
- [ ] Include text overlays for key features (optional)
- [ ] Add background music (if desired, keep it subtle)
- [ ] Ensure consistent audio levels
- [ ] Add intro/outro screens (optional)
- [ ] Include branding/logo (optional)
- [ ] Optimize video quality and file size

### Export Settings

- **Resolution**: 1920x1080 (Full HD) or higher
- **Frame Rate**: 30fps or 60fps
- **Format**: MP4 (H.264 codec)
- **Aspect Ratio**: 16:9
- **Audio**: AAC, 128kbps or higher

### Upload to YouTube

1. Upload video to YouTube
2. Set title: "HomeApp Demo - Property Management Made Intelligent"
3. Add description with key features
4. Set thumbnail (choose engaging frame)
5. Add tags: property management, AI, home maintenance, etc.
6. Set visibility (unlisted for review, public when ready)
7. Copy video ID for integration

### Integration

After uploading:
1. Copy the YouTube video ID from the URL
2. Set environment variable: `NEXT_PUBLIC_DEMO_VIDEO_ID=<video-id>`
3. Test the video modal on the landing page
4. Verify "Watch Demo" buttons work correctly
