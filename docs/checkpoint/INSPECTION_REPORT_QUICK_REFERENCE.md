# Inspection Report Feature - Quick Reference

## 📋 Quick Overview

Upload professional inspection reports (PDFs, images, Word docs) as checkpoints. AI automatically extracts findings, issues, and recommendations.

---

## 🚀 Quick Start

### Mobile App
1. Tap **Create Checkpoint** → **Inspection Report**
2. Select document (PDF/image/Word)
3. Fill in name, type, location
4. Tap **Create Checkpoint**
5. AI analyzes in 30-60 seconds

### Web App
1. Click **Create Checkpoint** → **Inspection Report** tab
2. Upload document
3. Fill in details
4. Click **Create Checkpoint**
5. Processing dialog shows progress

## 🤖 What AI Extracts

✅ Inspector name & company  
✅ Inspection date  
✅ Overall condition (Excellent → Critical)  
✅ Summary of findings  
✅ All issues with severity:
  - 🔴 Critical (safety hazards)
  - 🟠 Major (significant defects)
  - 🟡 Moderate (address soon)
  - 🟢 Minor (cosmetic issues)  
✅ Recommendations  
✅ Cost estimates (if mentioned)

### Naming
✅ "Annual Home Inspection - Jan 2025"

## 🛠️ Troubleshooting

### Upload Failed
- Check file size (< 50 MB)
- Verify format (PDF/image/Word)
- Check internet connection
- Try different browser

### Analysis Failed
- Ensure document is readable
- Check if password-protected
- Verify text is clear
- Try re-uploading

### Missing Info
- Manually enter inspector name
- Check if info is in report
- Ensure text is not blurry
- View original document

## 🎓 Example Workflow

### Home Purchase Inspection

1. **Receive Report** from home inspector
2. **Upload** as "Pre-Purchase Home Inspection"
3. **AI Extracts** 15 issues (2 critical, 5 major, 8 minor)
4. **Take Photos** of critical issues
5. **Ask Chat**: "What are the critical issues?"
6. **Negotiate** with seller based on findings
7. **Track Repairs** with follow-up checkpoints

### Annual Maintenance

1. **Schedule** HVAC inspection
2. **Upload Report** when received
3. **Compare** with last year's report
4. **Ask Chat**: "What changed from last year?"
5. **Plan Repairs** based on recommendations
6. **Document Completion** with photos
